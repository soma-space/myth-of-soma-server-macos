# Provenance and scope

This repository contains macOS hosting scripts and configuration maintained by
the Soma community. It does not contain Myth of Soma game binaries or database
assets. `make fetch` downloads the checksum-pinned distribution published by
[`soma-space/myth-of-soma-server-windows`](https://github.com/soma-space/myth-of-soma-server-windows).

The recovered server distribution combines community-preserved Myth of Soma
server files with Rauban's open-source Shinra extension. See the Windows
distribution's `NOTICE.md` and `docs/RECOVERY.md` for file-level provenance,
checksums, and repair details.

Myth of Soma names and original assets remain the property of their respective
owners. This project is an independent preservation and interoperability effort.

CrossOver is a CodeWeavers product. Microsoft SQL Server and the Microsoft ODBC
Driver are Microsoft products and are governed by their own licences and terms.
